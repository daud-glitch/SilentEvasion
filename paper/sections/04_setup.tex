\section{Experimental Setup}
\label{sec:setup}

\paragraph{Data.}
Two triage tasks. \emph{SMS smishing} uses the UCI SMS Spam Collection
(5{,}574 messages, 747 labelled spam), with spam treated as malicious. The task
label is therefore ``SMS spam/smishing''; the collection's spam class is
dominated by scam and prize messages rather than by credential-harvesting links,
and we flag this as a construct-validity limit rather than hide it.
\emph{Phishing e-mail} uses the \texttt{zefang-liu/phishing-email-dataset}
text column, filtered to messages between 16 and 3{,}000 characters and
balanced-sampled to 1{,}000 benign and 1{,}000 phishing rows with a fixed seed.

\paragraph{Splits.}
The evaluation split is balanced and frozen: 200 benign and 200 malicious rows
per task, 800 rows in total, drawn with seed 42. The split is byte-identical
across every run, and its fingerprint is asserted by the artefact's bootstrap
step, so a run that uses different data fails before it can report a number.
Attacks are launched on the caught subset \emph{of this evaluation split}, which
is a within-sample design: the same 800 rows supply both the baseline and the
attack set. We state this because it means the ASR is not an out-of-sample
estimate; it is a conditional measurement on the messages the model got right,
which is what Rule~1 defines.

\paragraph{Models.}
Three open instruction-tuned models, all quantisation-free at inference:
Qwen2.5-3B-Instruct, SmolLM2-1.7B-Instruct and Phi-3.5-mini-instruct
(3.8B). A fourth model, Llama-3.2-3B-Instruct, was planned but is gated behind a
licence acceptance and is not part of any number reported here.

\paragraph{Inference.}
All models are served behind one OpenAI-compatible endpoint and queried with the
same message list. Generation is greedy (temperature 0), capped at 8 new tokens,
with a single-word answer parser that returns malicious, benign, or
\emph{unparsed}; unparsed verdicts are counted separately and never guessed. In
the runs reported here, no verdict failed to parse. Models are loaded in
half precision on one T4 GPU with automatic device placement.

\paragraph{Compute and cost.}
One full run --- clean baseline on 800 rows for three models, construction of
the attack set, and both attack modes for all three models --- takes 37.1
minutes on a single free-tier T4. The reporting step is a separate pass over the
per-sample CSVs and runs on CPU.

\paragraph{Evaluation pipeline.}
Figure~\ref{fig:pipeline} shows the full pipeline. A message is classified by
the model. If the verdict is malicious, the message enters the attack set. The
perturbation engine applies edits and re-queries the model. The results are then
evaluated for transfer and defense robustness.

\paragraph{Reproducibility.}
Splits, prompt, decoding and per-sample perturbation seeds are fixed. The study
was run twice end to end (two independent GPU sessions); per-sample comparison
of the two runs, joined on sample id, gives identical attacked ids and identical
success flags in all six result files, with differences only in empty cells of
the excluded rows. The second run is the one whose outputs are reported here.
